# 南头古城定制路线网站雏形

这是基于现有 HTML Demo 整理的静态网站版本，适合先部署成一个可通过网址访问的手机网站。

## 当前已包含
- 32 个演示景点与四类筛选：研学、拍照、美食、购物
- 点击景点查看详情
- 加入“我的线路”
- 已选景点在普通地图中显示为灰色，在“我的线路”中恢复分类颜色
- 橙色线按景点顺序连接，不再自动把最后一个点闭合回第一个点
- 当前浏览器本地保存已选景点
- 为未来经纬度到自绘地图 XY 坐标转换预留了说明

## 重要说明
- 目前的景点名称、简介和地图位置属于演示数据，不应当作真实南头古城地点资料。
- 目前页面仍使用示意底图。你们有正式自绘地图图片后，需要替换底图，并根据图片显示区域校准 32 个景点的百分比坐标。
- 本版本尚未接入真实定位、云端存储、多设备同步、真实步行路线或路线最短化算法。
- localStorage 只保存在当前浏览器/设备中；换设备打开网址不会自动同步。

## 本地测试
直接用浏览器打开 `index.html` 即可测试基础交互。定位功能未来需要通过 HTTPS 网站和用户授权来测试。

## 发布成网址（GitHub Pages 方案）
1. 登录 GitHub 并创建一个新的公开仓库，例如 `nantou-route`。
2. 上传本文件夹中的 `index.html`，文件必须位于仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择从分支部署（Deploy from a branch），分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待 GitHub Pages 部署完成，页面会显示公开网址。把该网址发给其他人即可访问。

如果你们不想公开源代码，可以改用支持私有仓库/静态托管的其他服务；具体免费额度、访问限制及服务条款需要以平台当前政策为准。
